# Visual style guide

## Base style block (paste at the start of every image prompt, then adapt)
> Stylized 3D animated feature-film still, vertical 9:16 composition, soft subsurface
> skin shading, large expressive eyes, gently exaggerated proportions, detailed
> cloth and hair, cinematic lighting, shallow depth of field, volumetric atmosphere,
> rich colour grading, high detail, no text, no watermark.

## Lighting arc (carry the emotion with colour)
| Act | Palette | Light |
|-----|---------|-------|
| Setup / need | desaturated blues, grey | cold rain, overcast dusk, hard rim light |
| Kindness | one warm accent appears (the symbolic object's colour) | street lamp / shop window glow |
| Time jump | transition shot: same place, different season or brighter | — |
| Payoff | warm amber + saturated accents | golden practicals, bokeh, wet-street reflections |

## Framing for 9:16
- Keep faces in the upper third; leave the bottom ~20% clear for captions and UI.
- Close-ups of hands + symbolic object are the most "shareable" frames — include ≥ 2.
- Final shot: two-shot or hug, centred, held still for 2+ s.

## Character consistency checklist
- Each character: one signature colour + one silhouette feature (beanie, curly white
  hair, oversized hoodie, yellow raincoat).
- Generate a reference sheet per character (and per age, if they age), then pass it as
  a reference image to every keyframe they appear in.
- Reuse identical description wording in every prompt.

## Avoid
- Recognisable characters, studio names ("Pixar", "Disney") or their characters in prompts.
- Real brands, logos, readable store names other than invented ones.
- Uncanny realism — stay stylized.
