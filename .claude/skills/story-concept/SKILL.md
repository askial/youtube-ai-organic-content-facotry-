# Story Concept

Read `channel.yaml` and `references/formulas.md` first.

## Process
1. Pick a formula from `references/formulas.md` (rotate — check existing
   `productions/*/concept.md` so the channel doesn't repeat the same formula or setting
   twice in a row).
2. Brainstorm 5 loglines silently; keep the one with the strongest **visual** payoff
   (it must be understood with the sound off).
3. Write `productions/<slug>/concept.md` using the template below. `<slug>` is
   kebab-case, ≤ 5 words, e.g. `lantern-keeper-returns`.

## Rules
- Story told through images, not dialogue. At most 1–3 short spoken lines total, all in
  the payoff. Everything else is action and expression.
- One clear **symbolic object** that carries the story across time (the reference used
  an umbrella). It appears in the setup, the turn, and the payoff.
- A **time jump** ("years later") is the default engine of the twist.
- 2–3 characters max, each visually distinctive by silhouette + one signature colour.
- Setting has a strong weather/light motif (rain, snow, autumn dusk, lanterns) — it is
  what makes keyframes look cinematic.
- Kid-safe, no real brands, no existing IP characters.

## Template
```markdown
# <Title>
**Slug:** <slug>   **Formula:** <formula name>   **Target length:** <s>
**Logline:** <one sentence>
**Symbolic object:** <object + signature colour>
**Setting / light motif:** <...>

## Characters
- **<id>** — <name>, age, look (silhouette, hair, clothes, signature colour), core trait.
  If they age across the time jump, describe both versions (`<id>_young`, `<id>_old`).

## Beats
1. HOOK (0–3 s): <the image that stops the scroll — a striking need or contrast>
2. SETUP: ...
3. ACT OF KINDNESS / CHOICE: ...
4. CONSEQUENCE / SMALL WIN: ...
5. TIME JUMP: ...
6. REVEAL: ...
7. PAYOFF (the twist, + the 1–3 spoken lines, if any): ...
8. BUTTON (final 2 s hold on the emotional image): ...

## Spoken lines / captions
- "<line>" — <who>
```
